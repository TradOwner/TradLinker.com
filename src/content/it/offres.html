🚀 Come passare un server a Premium

  1. Dal server che vuoi passare a Premium, esegui il comando /8-buy_premium.
  2. Il bot genera e invia un link di pagamento Stripe (provider di pagamento sicuro) per sottoscrivere il piano Premium del server.
  3. Una volta ricevuto e confermato il pagamento, il server viene registrato automaticamente come Premium.

Il comando deve essere eseguito nel server interessato, perché l'abbonamento Premium è legato a quel server.

💎 Come diventare utente Platinium

  1. Esegui il comando /6-buy_platinium (server, DM o canale privato).
  2. Il bot crea/mostra il link sicuro di abbonamento per completare l'iscrizione Platinium.
  3. Dopo la conferma del pagamento, l'account utente viene registrato automaticamente come Platinium.

Questo abbonamento è legato all'utente (non a un intero server).
