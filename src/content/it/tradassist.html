Perché piace agli utenti

Un assistente semplice per gli utenti, potente per i server

TradAssist può essere usato nei messaggi diretti per uso personale, ma anche direttamente sui server come estensione di traduzione. Porta le azioni di traduzione rapide della suite nell'uso quotidiano.

1

Traduzioni rapide, senza configurazioni complesse

Traduci un messaggio, testo digitato o un canale recente tramite comandi slash e menu contestuali.

  • Utilizzabile nei DM e sui server (a seconda del comando)
  • Risposte effimere per mantenere pulito il canale
  • Selezione automatica della lingua di destinazione in base alla locale
2

Pubblica contenuti multilingue

Crea post con testo + allegati e un Translate pulsante, poi permette di modificare facilmente quei post.

  • Creazione rapida (allegati + modale)
  • Pulsante Translate per i lettori
  • Modifica dei messaggi del bot con il corretto flusso di autorizzazioni
3

Reazioni con bandiere = traduzione istantanea

I membri reagiscono con una bandiera riconosciuta e TradAssist invia una traduzione temporanea del messaggio.

  • Molto intuitivo per i membri
  • Ritardo di eliminazione automatica configurabile
  • Elenco delle bandiere riconosciute disponibile tramite comando

Comandi

Funzioni TradAssist (per utenti e server)

Elenco completo di comandi slash e menu contestuali. Quote e uso illimitato dipendono dal piano (Free, server Premium, utente Platinium).

✍️ Traduci e invia testo

  • /1-translate_and_send — apre un selettore di lingua, poi un modulo di testo per tradurre/inviare
  • Disponibile su server, nei DM e nei canali privati
  • Ideale per scrivere rapidamente un messaggio in un'altra lingua

🧾 Post multilingue con pulsante Translate

  • /2-multilang_post_create — crea un post (testo + fino a 5 allegati) con un Translate pulsante
  • /2-multilang_post_edit — modifica un post esistente del bot (testo + sostituzione opzionale degli allegati)
  • Può essere usato su server, nei DM e nei canali privati

📚 Traduzione canale (server)

  • /3-translate_channel — traduce gli N messaggi più recenti del canale (max 100) con paginazione
  • Menu contestuale Translate channel — apre lo stesso flusso da un messaggio
  • Comando solo server (niente DM)

💬 Traduci un messaggio specifico

  • /4-translate_message — traduce un messaggio del canale corrente (tramite ID messaggio)
  • Menu contestuale Translate message — il metodo più semplice (clic destro / Apps)
  • Disponibile su server, nei DM e nei canali privati
  • Risposta effimera, utile per tradurre senza riempire il canale

🚩 Traduzione tramite reazioni con bandiere

  • Funzione solo server: i membri reagiscono con una bandiera riconosciuta per ottenere una traduzione temporanea
  • /5-flagreact set_delay — imposta il ritardo di eliminazione automatica (da 5 a 300 s)
  • /5-flagreact show — mostra il ritardo attuale
  • /5-flagreact list_flags — elenca le bandiere riconosciute

Impostazione set_delay: comando server che richiede Manage Server o autorizzazioni da amministratore.

💎 Abbonamento utente

  • /6-buy_platinium — apre/guida il flusso di abbonamento Platinium
  • Comando disponibile su server, nei DM e nei canali privati
  • Utile per l'uso personale illimitato delle funzioni supportate
Da ricordare: TradAssist è il bot più diretto della suite. Può aiutare un singolo utente nei DM or diventare un'estensione di traduzione completa per un server — soprattutto insieme a TradLinker.
