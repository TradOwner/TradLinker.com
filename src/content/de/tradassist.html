Persönlicher Assistent & Server-Erweiterung

TradAssist

Ein vielseitiger Übersetzungsassistent: Übersetzungen auf Abruf, Übersetzung einzelner Nachrichten oder Kanäle, mehrsprachige Beiträge mit Translate-Schaltfläche und Übersetzung per Flaggenreaktion.

Warum Nutzer es mögen

Ein einfacher Assistent für Nutzer, leistungsstark für Server

TradAssist kann für den persönlichen Gebrauch in Direktnachrichten, aber auch direkt auf Servern als Übersetzungserweiterung verwendet werden. Es bringt die schnellen Übersetzungsaktionen der Suite in den Alltag.

1

Schnelle Übersetzungen ohne komplizierte Einrichtung

Übersetze eine Nachricht, eingegebenen Text oder einen aktuellen Kanal über Slash-Befehle und Kontextmenüs.

  • In DMs und auf Servern nutzbar (je nach Befehl)
  • Ephemere Antworten, damit der Kanal sauber bleibt
  • Automatische Zielsprache anhand der Locale
2

Mehrsprachige Inhalte veröffentlichen

Erstellt Beiträge mit Text + Anhängen und einer Translate Schaltfläche und ermöglicht anschließend die einfache Bearbeitung dieser Beiträge.

  • Schnelle Erstellung (Anhänge + Modal)
  • Translate-Schaltfläche für Leser
  • Bearbeitung von Bot-Nachrichten mit dem richtigen Berechtigungsablauf
3

Flaggenreaktionen = sofortige Übersetzung

Mitglieder reagieren mit einer erkannten Flagge und TradAssist sendet eine temporäre Übersetzung der Nachricht.

  • Sehr intuitiv für Mitglieder
  • Konfigurierbare Verzögerung für automatisches Löschen
  • Liste erkannter Flaggen per Befehl verfügbar

TradAssist-Funktionen (für Nutzer und Server)

Vollständige Liste der Slash-Befehle und Kontextmenüs. Kontingente und unbegrenzte Nutzung hängen vom Tarif ab (Free, Server Premium, Nutzer Platinium).

✍️ Text übersetzen & senden

  • /1-translate_and_send — öffnet eine Sprachauswahl und anschließend ein Textformular zum Übersetzen/Senden
  • Auf Servern, in DMs und privaten Kanälen verfügbar
  • Ideal, um schnell eine Nachricht in einer anderen Sprache zu schreiben

🧾 Mehrsprachige Beiträge mit Translate-Schaltfläche

  • /2-multilang_post_create — erstellt einen Beitrag (Text + bis zu 5 Anhänge) mit einer Translate Schaltfläche
  • /2-multilang_post_edit — bearbeitet einen bestehenden Bot-Beitrag (Text + optionaler Austausch von Anhängen)
  • Kann auf Servern, in DMs und privaten Kanälen verwendet werden

📚 Kanalübersetzung (Server)

  • /3-translate_channel — übersetzt die N neuesten Nachrichten aus dem Kanal (max. 100) mit Seitennavigation
  • Kontextmenü Translate channel — öffnet denselben Ablauf aus einer Nachricht heraus
  • Nur-Server-Befehl (keine DMs)

💬 Eine bestimmte Nachricht übersetzen

  • /4-translate_message — übersetzt eine Nachricht aus dem aktuellen Kanal (über Nachrichten-ID)
  • Kontextmenü Translate message — die einfachste Methode (Rechtsklick / Apps)
  • Auf Servern, in DMs und privaten Kanälen verfügbar
  • Ephemere Antwort, nützlich zum Übersetzen, ohne den Kanal zu überladen

🚩 Übersetzung über Flaggenreaktionen

  • Nur-Server-Funktion: Mitglieder reagieren mit einer erkannten Flagge, um eine temporäre Übersetzung zu erhalten
  • /5-flagreact set_delay — legt die Verzögerung für automatisches Löschen fest (5 bis 300 s)
  • /5-flagreact show — zeigt die aktuelle Verzögerung
  • /5-flagreact list_flags — listet erkannte Flaggen auf

Einstellung set_delay: Server-Befehl, der Manage Server oder Administratorberechtigungen erfordert.

💎 Nutzerabonnement

  • /6-buy_platinium — öffnet/führt durch den Platinium-Abonnementablauf
  • Befehl auf Servern, in DMs und privaten Kanälen verfügbar
  • Nützlich für unbegrenzte persönliche Nutzung unterstützter Funktionen
Beachte: TradAssist ist der direkteste Bot der Suite. Er kann einen Nutzer in DMs unterstützen or zu einer vollständigen Übersetzungserweiterung für einen Server werden — besonders zusammen mit TradLinker.
