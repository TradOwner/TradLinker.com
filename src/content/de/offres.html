🚀 So stellst du einen Server auf Premium um

  1. Führe auf dem Server, den du auf Premium upgraden möchtest,den Befehl aus /8-buy_premium.
  2. Der Bot erzeugt und sendet einen Stripe-Zahlungslink (sicherer Zahlungsanbieter), um den Premium-Tarif des Servers zu abonnieren.
  3. Sobald die Zahlung eingegangen und bestätigt ist, wird der Server automatisch als Premium registriert.

Der Befehl muss auf dem Zielserver ausgeführt werden, da das Premium-Abonnement an diesen Server gebunden ist.

💎 So wirst du Platinium-Nutzer

  1. Führe den Befehl aus /6-buy_platinium (Server, DM oder privater Kanal).
  2. Der Bot erstellt/zeigt den sicheren Abonnement-Link an, um die Platinium-Anmeldung abzuschließen.
  3. Sobald die Zahlung bestätigt ist, wird das Benutzerkonto automatisch als Platinium registriert.

Dieses Abonnement ist an den Nutzer gebunden (nicht an einen ganzen Server).
