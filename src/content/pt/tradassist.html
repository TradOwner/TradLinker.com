Porque os utilizadores gostam

Um assistente simples para utilizadores, poderoso para servidores

O TradAssist pode ser utilizado em mensagens diretas para uso pessoal, mas também diretamente em servidores como extensão de tradução. Leva as ações rápidas de tradução da suite para a utilização diária.

1

Traduções rápidas, sem configuração complexa

Traduza uma mensagem, texto escrito ou um canal recente através de comandos slash e menus de contexto.

  • Utilização em DMs e servidores (consoante o comando)
  • Respostas efémeras para manter o canal limpo
  • Seleção automática do idioma de destino com base na região
2

Publique conteúdo multilingue

Cria publicações com texto + anexos e um Translate botão, permitindo depois editar facilmente essas publicações.

  • Criação rápida (anexos + modal)
  • Botão Translate para leitores
  • Edição de mensagens do bot com o fluxo de permissões correto
3

Reações com bandeiras = tradução instantânea

Os membros reagem com uma bandeira reconhecida e o TradAssist envia uma tradução temporária da mensagem.

  • Muito intuitivo para os membros
  • Atraso de eliminação automática configurável
  • Lista de bandeiras reconhecidas disponível por comando

Comandos

Funcionalidades do TradAssist (para utilizadores e servidores)

Lista completa de comandos slash e menus de contexto. As quotas e a utilização ilimitada dependem do plano (Free, servidor Premium, utilizador Platinium).

✍️ Traduzir e enviar texto

  • /1-translate_and_send — abre um seletor de idioma e depois um formulário de texto para traduzir/enviar
  • Disponível em servidores, DMs e canais privados
  • Ideal para escrever rapidamente uma mensagem noutro idioma

🧾 Publicações multilingues com botão Translate

  • /2-multilang_post_create — cria uma publicação (texto + até 5 anexos) com um Translate botão
  • /2-multilang_post_edit — edita uma publicação existente do bot (texto + substituição opcional de anexos)
  • Pode ser utilizado em servidores, DMs e canais privados

📚 Tradução de canal (servidor)

  • /3-translate_channel — traduz as N mensagens mais recentes do canal (máx. 100) com paginação
  • Menu de contexto Translate channel — abre o mesmo fluxo a partir de uma mensagem
  • Comando apenas para servidores (sem DMs)

💬 Traduzir uma mensagem específica

  • /4-translate_message — traduz uma mensagem do canal atual (através do ID da mensagem)
  • Menu de contexto Translate message — o método mais simples (clique direito / Apps)
  • Disponível em servidores, DMs e canais privados
  • Resposta efémera, útil para traduzir sem encher o canal

🚩 Tradução através de reações com bandeiras

  • Funcionalidade apenas para servidores: os membros reagem com uma bandeira reconhecida para obter uma tradução temporária
  • /5-flagreact set_delay — define o atraso de eliminação automática (5 a 300 s)
  • /5-flagreact show — mostra o atraso atual
  • /5-flagreact list_flags — lista as bandeiras reconhecidas

Definição set_delay: comando de servidor que requer Manage Server ou permissões de administrador.

💎 Subscrição de utilizador

  • /6-buy_platinium — abre/orienta o fluxo de subscrição Platinium
  • Comando disponível em servidores, DMs e canais privados
  • Útil para utilização pessoal ilimitada das funcionalidades suportadas
Tenha em conta: O TradAssist é o bot mais direto da suite. Pode apoiar um utilizador em DMs or tornar-se uma extensão completa de tradução para um servidor — especialmente em conjunto com o TradLinker.
