TradLinker 的作用

一场对话，多种语言

TradLinker 用于避免讨论碎片化。无需拆分社区，只需创建一个频道组（FR、EN、ES 等），机器人便会将每条消息翻译后转发到组内其他频道。

1

关联频道组

创建组（例如 综合），然后为每种语言添加一个频道。TradLinker 就会知道每条消息应重新发布到哪里。

  • 按组组织（例如：综合、支持、招募）
  • 组内一个频道 = 一种语言
  • 配置始终可见且可随时编辑
2

自动转发 + 翻译

成员在关联频道发消息时，该消息会以适合各语言的译文重新发布到同组其他频道。

  • 成员体验流畅
  • 跨语言的统一对话
  • 自动同步转发消息上的表情反应、Discord 回复和原位编辑
  • 可通过表情反应查看器查看反应
3

内置多语言投票

你可以从关联频道发起投票，机器人会把带翻译选项的投票发布到组内所有频道。

  • 问题 + 选项按语言翻译
  • 在关联频道间同步发布
  • 由创建者（或管理员）辅助删除投票

命令

管理员 / 版主每天需要的一切

以下是用户/管理员可见的命令和操作。

🧭 开始使用

  • /help — TradLinker 快速设置指南（组、频道、Premium、支持）
  • 需要知道： 机器人会逐步引导你完成设置逻辑，让你快速开始

🛠️ 组配置（服务器管理员）

  • /2-create_group — 创建关联频道组
  • /3-add_channel — 将频道加入组，然后提示选择语言
  • /4-remove_channel — 从组中移除频道
  • /5-delete_group — 删除整个组
  • /6-show_groups — 显示当前配置（组 + 频道 + 语言）

主要用于服务器 • 配置命令需要 Manage Channels 权限。

📊 多语言投票

  • /1-create_poll — 在关联频道创建投票并发布到组内关联频道
  • /1-delete_poll — 删除你创建的投票（管理员可以删除所有投票）
  • 内置持续时间预设（15 分钟到 3 天）
  • 文本选项（完整使用时每个答案可选配图片）

💬 表情反应查看器

  • 上下文菜单 Show reactions — 汇总显示消息的表情反应
  • 在转发 / 翻译消息系统中非常实用

💎 支持与服务器订阅

  • /7-donate — 支持项目
  • /8-buy_premium — 当前服务器的 Premium 订阅

Premium 会提高组和频道限制，开放 TradCoord（成员引导、规则、协调和身份组分配），并允许在该服务器上无限使用 TradAssist。

🎯 最适合什么用途？

  • 国际社区（游戏、创作者、支持、开源）
  • 希望保持 一个统一社区 而不按语言拆分的服务器
  • 需要简单、可靠且易于管理配置的团队
Free 与 Premium 套餐： TradLinker 已包含核心多语言聊天系统。Premium 提高配置限制（组/频道），增加 TradCoord 成员引导、协调和身份组分配，并让支持的 TradAssist 功能在服务器上无限使用。
