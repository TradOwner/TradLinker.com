个人助手与服务器扩展

TradAssist

多功能翻译助手：按需翻译、单条消息或频道翻译、带 Translate 按钮的多语言发布，以及旗帜反应翻译。

DM + 服务器消息翻译频道翻译多语言发布旗帜反应
添加 TradAssist 查看 Premium / Platinium

用户喜欢它的原因

对用户简单，对服务器强大

TradAssist 既可在私信中作为个人工具使用，也可直接在服务器上作为翻译扩展。它把 Suite 的快捷翻译操作带入日常使用。

1

快速翻译，无需复杂设置

通过 Slash 命令和上下文菜单翻译一条消息、输入的文本或最近的频道内容。

  • 可用于 DM 和服务器（视命令而定）
  • 临时响应，让频道保持整洁
  • 根据区域设置自动选择目标语言
2

发布多语言内容

创建包含文本 + 附件并带有 Translate 按钮的帖子，然后可轻松编辑这些帖子。

  • 快速创建（附件 + 弹窗）
  • 供读者使用的 Translate 按钮
  • 按正确权限流程编辑机器人消息
3

旗帜反应 = 即时翻译

成员用受支持的旗帜作出反应后，TradAssist 会发送该消息的临时翻译。

  • 对成员非常直观
  • 可配置自动删除延迟
  • 可通过命令查看支持的旗帜列表

命令

TradAssist 功能（用户和服务器）

Slash 命令和上下文菜单的完整列表。配额和无限使用取决于套餐（Free、服务器 Premium、用户 Platinium）。

✍️ 翻译并发送文本

  • /1-translate_and_send — 打开语言选择器，然后打开用于翻译/发送的文本表单
  • 可用于服务器、DM 和私密频道
  • 非常适合快速用另一种语言写消息

🧾 带 Translate 按钮的多语言发布

  • /2-multilang_post_create — 创建一个包含文本 + 最多 5 个附件并带有 Translate 按钮
  • /2-multilang_post_edit — 编辑现有机器人帖子（文本 + 可选附件替换）
  • 可用于服务器、DM 和私密频道

📚 频道翻译（服务器）

  • /3-translate_channel — 翻译频道中的 最近 N 条消息 （最多 100 条），支持分页
  • 上下文菜单 Translate channel — 从消息中打开相同流程
  • 仅限服务器命令（不支持 DM）

💬 翻译指定消息

  • /4-translate_message — 通过消息 ID 翻译当前频道中的一条消息
  • 上下文菜单 Translate message — 最简单的方法（右键 / Apps）
  • 可用于服务器、DM 和私密频道
  • 临时响应，可翻译而不干扰频道

🚩 通过旗帜反应翻译

  • 仅限服务器：成员使用受支持旗帜反应即可获得临时翻译
  • /5-flagreact set_delay — 设置自动删除延迟（5 到 300 秒）
  • /5-flagreact show — 显示当前延迟
  • /5-flagreact list_flags — 列出支持的旗帜

设置 set_delay：服务器命令，需要 Manage Server 或管理员权限。

💎 用户订阅

  • /6-buy_platinium — 打开/引导 Platinium 订阅流程
  • 可用于服务器、DM 和私密频道的命令
  • 适合无限个人使用支持的功能
请记住： TradAssist 是 Suite 中最直接的机器人。它可以在 DM 中帮助单个用户， or 也可以成为完整的服务器翻译扩展 — 尤其与 TradLinker 搭配使用时。
