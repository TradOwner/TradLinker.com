为什么选择这套 Suite？

清晰的架构：1 个主机器人 + 2 个互补扩展

三个机器人这样协同工作： TradLinker 是主机器人， TradCoord 是 Premium 的成员引导、协调和身份组管理附加组件，而 TradAssist 既可作为个人助手，也可作为服务器翻译扩展。

1

从 TradLinker 开始

创建关联频道组（FR / EN / ES…），让机器人转发/翻译消息，从而维持一场不被拆分的统一对话。

  • 频道间自动翻译
  • 同步表情反应
  • 多语言投票
2

添加 TradAssist 用于日常使用

按需翻译、频道翻译和带有 Translate 按钮的多语言发布，以及旗帜反应翻译。在 Premium 中，核心功能对该服务器所有成员无限开放。

  • DM 中的个人助手
  • 服务器翻译工具
  • Premium 服务器无限使用（支持的功能）
3

使用 Premium 解锁 TradCoord

清晰、安全的成员引导：欢迎消息、规则接受、语言选择、多组协调，以及为当前或未来成员分配身份组。

  • 欢迎与规则
  • 语言身份组与协调
  • 批量或自动分配

主机器人

TradLinker

多语言服务器的核心。 按语言连接多个频道，并将每条翻译后的消息重新发布到关联频道。

关联频道自动翻译投票表情反应同步
核心功能 / 命令
  • /2-create_group, /3-add_channel, /6-show_groups
  • /1-create_poll and /1-delete_poll
  • 上下文菜单 Show reactions （表情反应汇总）
  • /8-buy_premium 适用于 Premium 服务器

助手与扩展

TradAssist

个人翻译助手……也是 TradLinker 的服务器扩展。 可在 DM 和服务器中使用的高级翻译工具。

消息翻译频道翻译多语言发布旗帜反应
核心功能 / 命令
  • /1-translate_and_send • /4-translate_message
  • /3-translate_channel + 上下文菜单 Translate channel
  • /2-multilang_post_create / edit 带有 Translate 按钮
  • /5-flagreact 命令组（旗帜 + 延迟）
  • /6-buy_platinium — 用户 Platinium 套餐

Premium 扩展

TradCoord

面向 Premium 服务器的智能成员引导。 欢迎成员、管理规则和语言身份组、协调访问并自动化身份组分配。

欢迎规则语言身份组协调自动身份组
核心功能 / 命令
  • /1-set_welcome • /1-clear_welcome
  • /2-set_rules_message （接受按钮 + 日志）
  • /3-coordination, /3-edit_coordination, /3-delete_coordination
  • /4-role_assignment • /4-stop_role_assignment （批量和自动分配）
  • 仅限 Premium

工作流程

3 个机器人如何互相补充

1

TradLinker 组织对话

按语言分组的关联频道、自动转发和翻译：让对话保持活跃与统一。

2

TradAssist 增加高级工具

按需翻译、频道翻译、多语言发布和旗帜反应 — 可在 DM 和/或服务器中使用。

3

TradCoord 组织 Premium 成员引导和身份组

规则、语言、身份组和访问：清晰流程、交互式语言选择，以及为当前或未来成员自动分配身份组。
