Почему он нравится пользователям

Простой ассистент для пользователей, мощный инструмент для серверов

TradAssist можно использовать в личных сообщениях для себя, а также прямо на серверах как расширение перевода. Он переносит быстрые действия перевода Suite в повседневное использование.

1

Быстрые переводы без сложной настройки

Переводите сообщение, введённый текст или недавние сообщения канала через slash-команды и контекстные меню.

  • Использование в ЛС и на серверах (в зависимости от команды)
  • Эфемерные ответы, чтобы канал оставался чистым
  • Автоматический выбор целевого языка по локали
2

Публикация многоязычного контента

Создаёт публикации с текстом + вложениями и Translate кнопкой, после чего позволяет легко их редактировать.

  • Быстрое создание (вложения + модальное окно)
  • Кнопка Translate для читателей
  • Редактирование сообщений бота с правильным процессом разрешений
3

Реакции флагами = мгновенный перевод

Участник ставит реакцию распознаваемым флагом, и TradAssist отправляет временный перевод сообщения.

  • Очень интуитивно для участников
  • Настраиваемая задержка автоудаления
  • Список распознаваемых флагов доступен по команде

Команды

Функции TradAssist (для пользователей и серверов)

Полный список slash-команд и контекстных меню. Квоты и безлимитное использование зависят от тарифа (Free, сервер Premium, пользователь Platinium).

✍️ Перевести и отправить текст

  • /1-translate_and_send — открывает выбор языка, затем текстовую форму для перевода/отправки
  • Доступно на серверах, в ЛС и приватных каналах
  • Идеально, чтобы быстро написать сообщение на другом языке

🧾 Многоязычные публикации с кнопкой Translate

  • /2-multilang_post_create — создаёт публикацию (текст + до 5 вложений) с Translate кнопкой
  • /2-multilang_post_edit — редактирует существующую публикацию бота (текст + необязательная замена вложений)
  • Можно использовать на серверах, в ЛС и приватных каналах

📚 Перевод канала (сервер)

  • /3-translate_channel — переводит N последних сообщений канала (макс. 100) с постраничным просмотром
  • Контекстное меню Translate channel — открывает тот же процесс из сообщения
  • Только для серверов (не работает в ЛС)

💬 Перевести конкретное сообщение

  • /4-translate_message — переводит сообщение из текущего канала по ID сообщения
  • Контекстное меню Translate message — самый простой способ (правый клик / Apps)
  • Доступно на серверах, в ЛС и приватных каналах
  • Эфемерный ответ — удобно переводить, не засоряя канал

🚩 Перевод через реакции флагами

  • Функция только для серверов: участники реагируют распознаваемым флагом и получают временный перевод
  • /5-flagreact set_delay — задаёт задержку автоудаления (от 5 до 300 с)
  • /5-flagreact show — показывает текущую задержку
  • /5-flagreact list_flags — показывает список распознаваемых флагов

Настройка set_delay: серверная команда, требующая Manage Server или прав администратора.

💎 Пользовательская подписка

  • /6-buy_platinium — открывает/проводит через оформление Platinium
  • Команда доступна на серверах, в ЛС и приватных каналах
  • Полезно для безлимитного личного использования поддерживаемых функций
Имейте в виду: TradAssist — самый прямой бот Suite. Он может помогать одному пользователю в ЛС or или стать полноценным расширением перевода для сервера — особенно вместе с TradLinker.
