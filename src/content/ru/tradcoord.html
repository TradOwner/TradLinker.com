Роль в Suite

После перевода работу продолжает TradCoord

TradCoord проводит новых участников через выбор языка, назначает правильный доступ и сокращает ненужные уведомления. Он также может раздать существующую роль всем текущим участникам и затем автоматизировать её для новых участников или при получении первой роли.

1

Настраиваемое приветствие

Настройте собственное приветственное сообщение, чтобы направлять участников в нужный канал (правила / выбор языка), не отправляя лишние уведомления всему серверу.

  • Свободный текст (через модальное окно)
  • Простые переменные {user} and {channel}
  • Кнопка, которая отправляет пользователей прямо в канал правил или выбора языка
2

Принятие правил

Публикует сообщение с правилами и кнопкой принятия, назначает пользователю роль, а затем перенаправляет к выбору языка, чтобы каждый участник мог настроить свой доступ.

  • Простой процесс для новых участников
  • Отслеживаемость для модерации
  • Явное перенаправление в канал выбора языка (самостоятельная настройка участниками)
3

Координация по областям

Создаёт интерактивные сообщения ролей/языков для одной, нескольких или всех групп TradLinker, чтобы участники выбирали язык и получали только полезные уведомления.

  • Выбрать одну или несколько групп TradLinker
  • Безопасно обновлять или удалять области координации
  • Языковые роли уменьшают лишние уведомления
4

Массовое и автоматическое назначение ролей

Выберите существующую роль, назначьте её подходящим текущим участникам, затем при необходимости выберите автоматическое правило для будущих участников.

  • Массовое назначение людям с соблюдением иерархии ролей Discord
  • Выберите режим автоматизации: при входе или при получении первой роли
  • Остановить автоматизацию без удаления уже назначенных ролей

Команды

Функции для администраторов (Premium)

Все команды ниже являются административными. TradCoord предназначен для Premium-серверов.

👋 Приветствие

  • /1-set_welcome — настраивает приветственное сообщение (целевой канал + текст в модальном окне)
  • /1-clear_welcome — отключает и удаляет настройку приветствия сервера

Разрешения: управление сообщениями. Только для Premium-серверов.

📜 Правила + подтверждение

  • /2-set_rules_message — отправляет сообщение о принятии правил с кнопкой
  • Публичные настройки: канал сообщения, канал логов, языковой канал, назначаемая роль
  • По нажатию: назначить роль + подтверждение + ссылка на канал выбора языка

🧩 Интерактивная координация (создание)

  • /3-coordination — создаёт интерактивное сообщение управления ролями в выбранном канале
  • Позволяет выбрать одну, несколько или все группы TradLinker
  • Создаёт/связывает языковые роли для выбранной области координации

✏️ Обслуживание координации

  • /3-edit_coordination — обновляет существующее сообщение координации (полезно после изменения групп/каналов)
  • /3-delete_coordination — удаляет область координации с подтверждением
  • По возможности безопасно очищает неиспользуемые разрешения/роли

Удаление: разрешения Управление сообщениями + Manage Roles.

👥 Массовое назначение ролей

  • /4-role_assignment — выбирает доступную для назначения существующую роль и раздаёт её текущим участникам, которыми бот может управлять
  • Выберите автоматическое назначение для новых участников или при получении участником первой роли
  • /4-stop_role_assignment — отключает автоматическое назначение настроенной роли
  • Остановка автоматизации не удаляет уже назначенные роли

Premium-сервер и Manage Roles требуемое разрешение. Первичное массовое назначение пропускает ботов и соблюдает иерархии ролей администратора и бота.

✅ Что это меняет для ваших участников

  • Более понятный процесс входа (приветствие + правила + выбор языка)
  • Меньше препятствий на пути к нужному контенту
  • Единообразное назначение общей роли без обработки участников по одному
  • Лучшая читаемость на крупных многоязычных серверах

🎯 Для каких серверов это подходит лучше всего?

  • Сообщества с серьёзными потребностями в онбординге (авторы, игры, поддержка, школы)
  • Серверы с множеством каналов/языков, которым нужна структура
  • Команды модерации, желающие экономить время на онбординге и общих ролях
Важно: TradCoord — это Premium-дополнение для TradLinker. Языковая координация использует группы и языки TradLinker; для массового или автоматического назначения можно использовать любую существующую роль, которой разрешено управлять и администратору, и боту.
