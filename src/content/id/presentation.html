Mengapa suite ini?

Arsitektur yang jelas: 1 bot utama + 2 ekstensi pelengkap

Berikut cara ketiga bot bekerja bersama: TradLinker adalah bot utama, TradCoord adalah add-on Premium untuk onboarding, koordinasi, dan pengelolaan peran, sedangkan TradAssist berfungsi sebagai asisten pribadi sekaligus ekstensi terjemahan server.

1

Mulai dengan TradLinker

Buat grup kanal tertaut (FR / EN / ES…) dan biarkan bot meneruskan/menerjemahkan pesan agar Anda mempertahankan satu percakapan tanpa terpecah.

  • Terjemahan otomatis antar kanal
  • Reaksi tersinkronisasi
  • Jajak pendapat multibahasa
2

Tambahkan TradAssist untuk penggunaan sehari-hari

Terjemahan sesuai permintaan, terjemahan kanal, dan posting multibahasa dengan Translate tombol, ditambah terjemahan melalui reaksi bendera. Pada Premium, fitur utama tanpa batas untuk semua orang di server tersebut.

  • Asisten pribadi di DM
  • Alat terjemahan server
  • Tanpa batas di server Premium (fitur yang didukung)
3

Dengan Premium, buka TradCoord

Onboarding yang rapi dan aman: pesan sambutan, penerimaan aturan, pemilihan bahasa, koordinasi multigrup, dan penetapan peran untuk anggota saat ini maupun mendatang.

  • Sambutan & aturan
  • Peran bahasa & koordinasi
  • Penetapan massal atau otomatis

Ketiga bot

Ikhtisar bot

Setiap blok membahas peran produk, fitur utama, dan penggunaan utamanya.

Bot utama

TradLinker

Inti dari server multibahasa. Menghubungkan beberapa kanal berdasarkan bahasa dan menerbitkan ulang setiap pesan terjemahan di kanal tertaut.

Kanal tertautTerjemahan otomatisJajak pendapatSinkronisasi reaksi
Fitur / perintah utama
  • /2-create_group, /3-add_channel, /6-show_groups
  • /1-create_poll and /1-delete_poll
  • Menu konteks Show reactions (agregasi reaksi)
  • /8-buy_premium untuk server Premium

Asisten & ekstensi

TradAssist

Asisten penerjemah pribadi… dan ekstensi server TradLinker. Alat terjemahan lanjutan yang dapat digunakan di DM dan server.

Terjemahan pesanTerjemahan kanalPosting multibahasaReaksi bendera
Fitur / perintah utama
  • /1-translate_and_send • /4-translate_message
  • /3-translate_channel + menu konteks Translate channel
  • /2-multilang_post_create / edit dengan Translate tombol
  • /5-flagreact grup perintah (bendera + jeda)
  • /6-buy_platinium — paket Platinium pengguna

Ekstensi Premium

TradCoord

Onboarding cerdas untuk server Premium. Menyambut anggota, mengelola aturan dan peran bahasa, mengoordinasikan akses, serta mengotomatiskan penetapan peran.

SambutanAturanPeran bahasaKoordinasiPeran otomatis
Fitur / perintah utama
  • /1-set_welcome • /1-clear_welcome
  • /2-set_rules_message (tombol penerimaan + log)
  • /3-coordination, /3-edit_coordination, /3-delete_coordination
  • /4-role_assignment • /4-stop_role_assignment (penetapan massal dan otomatis)
  • Khusus untuk Premium

Alur kerja

Bagaimana 3 bot saling melengkapi

1

TradLinker menata percakapan

Grup kanal tertaut berdasarkan bahasa, penerusan dan terjemahan otomatis: percakapan tetap aktif dan terpadu.

2

TradAssist menambahkan alat lanjutan

Terjemahan sesuai permintaan, terjemahan kanal, posting multibahasa, dan reaksi bendera — di DM dan/atau server.

3

TradCoord menata onboarding dan peran Premium

Aturan, bahasa, peran, dan akses: alur yang jelas, pemilihan bahasa interaktif, serta penetapan peran otomatis untuk anggota saat ini atau mendatang.
