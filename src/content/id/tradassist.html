Mengapa pengguna menyukainya

Asisten sederhana untuk pengguna, kuat untuk server

TradAssist dapat digunakan di pesan langsung untuk penggunaan pribadi, tetapi juga langsung di server sebagai ekstensi terjemahan. TradAssist menghadirkan tindakan terjemahan cepat suite ke penggunaan sehari-hari.

1

Terjemahan cepat, tanpa pengaturan rumit

Terjemahkan pesan, teks yang diketik, atau kanal terbaru melalui perintah slash dan menu konteks.

  • Gunakan di DM dan server (tergantung perintah)
  • Respons sementara agar kanal tetap bersih
  • Penargetan bahasa otomatis berdasarkan locale
2

Publikasikan konten multibahasa

Membuat posting dengan teks + lampiran dan Translate tombol, lalu memungkinkan Anda mengedit posting tersebut dengan mudah.

  • Pembuatan cepat (lampiran + modal)
  • Tombol Terjemahkan untuk pembaca
  • Pengeditan pesan bot dengan alur izin yang tepat
3

Reaksi bendera = terjemahan instan

Anggota bereaksi dengan bendera yang dikenali, lalu TradAssist mengirim terjemahan sementara dari pesan tersebut.

  • Sangat intuitif bagi anggota
  • Jeda hapus otomatis yang dapat dikonfigurasi
  • Daftar bendera yang dikenali tersedia melalui perintah

Perintah

Fitur TradAssist (untuk pengguna dan server)

Daftar lengkap perintah slash dan menu konteks. Kuota dan penggunaan tanpa batas bergantung pada paket (Free, Premium server, Platinium pengguna).

✍️ Terjemahkan & kirim teks

  • /1-translate_and_send — membuka pemilih bahasa, lalu formulir teks untuk menerjemahkan/mengirim
  • Tersedia di server, DM, dan kanal pribadi
  • Ideal untuk menulis pesan dengan cepat dalam bahasa lain

🧾 Posting multibahasa dengan tombol Terjemahkan

  • /2-multilang_post_create — membuat posting (teks + hingga 5 lampiran) dengan Translate tombol
  • /2-multilang_post_edit — mengedit posting bot yang sudah ada (teks + penggantian lampiran opsional)
  • Dapat digunakan di server, DM, dan kanal pribadi

📚 Terjemahan kanal (server)

  • /3-translate_channel — menerjemahkan N pesan terbaru dari kanal (maks. 100) dengan pagination
  • Menu konteks Translate channel — membuka alur yang sama dari sebuah pesan
  • Perintah khusus server (tanpa DM)

💬 Terjemahkan pesan tertentu

  • /4-translate_message — menerjemahkan pesan dari kanal saat ini (melalui ID pesan)
  • Menu konteks Translate message — metode termudah (klik kanan / Aplikasi)
  • Tersedia di server, DM, dan kanal pribadi
  • Respons sementara, berguna untuk menerjemahkan tanpa memenuhi kanal

🚩 Terjemahan melalui reaksi bendera

  • Fitur khusus server: anggota bereaksi dengan bendera yang dikenali untuk mendapatkan terjemahan sementara
  • /5-flagreact set_delay — mengatur jeda hapus otomatis (5 hingga 300 dtk)
  • /5-flagreact show — menampilkan jeda saat ini
  • /5-flagreact list_flags — menampilkan daftar bendera yang dikenali

Pengaturan set_delay: perintah server yang memerlukan Manage Server atau izin administrator.

💎 Langganan pengguna

  • /6-buy_platinium — membuka/memandu alur langganan Platinium
  • Perintah tersedia di server, DM, dan kanal pribadi
  • Berguna untuk penggunaan pribadi tanpa batas pada fitur yang didukung
Perlu diingat: TradAssist adalah bot paling langsung dalam suite. Bot ini dapat mendukung satu pengguna di DM or atau menjadi ekstensi terjemahan lengkap untuk server — terutama bersama TradLinker.
