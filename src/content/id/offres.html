🚀 Cara meningkatkan server ke Premium

  1. Dari server yang ingin Anda tingkatkan ke Premium, jalankan perintah /8-buy_premium.
  2. Bot membuat dan mengirim tautan pembayaran Stripe (penyedia pembayaran aman) untuk berlangganan paket Premium server.
  3. Setelah pembayaran diterima dan dikonfirmasi, server akan secara otomatis terdaftar sebagai Premium.

Perintah harus dijalankan di server target karena langganan Premium terikat pada server tersebut.

💎 Cara menjadi pengguna Platinium

  1. Jalankan perintah /6-buy_platinium (server, DM, atau kanal pribadi).
  2. Bot membuat/menampilkan tautan langganan aman untuk menyelesaikan pendaftaran Platinium.
  3. Setelah pembayaran dikonfirmasi, akun pengguna akan secara otomatis terdaftar sebagai Platinium.

Langganan ini terhubung ke pengguna (bukan ke seluruh server).
