Role in the suite

TradCoord takes over after translation

TradCoord guides new members through language selection, assigns the right access, and limits unnecessary notifications. It can also distribute an existing role to all current members, then automate it for new members or when they receive their first role.

1

Custom welcome

Set up a custom welcome message to guide members to the right channel (rules / language choice), without sending unnecessary notifications to the whole server.

  • Free text (via modal)
  • Simple variables {user} and {channel}
  • Button that sends users directly to the rules or language-selection channel
2

Rules acceptance

Publishes a rules message with an accept button, assigns a role to the user, then redirects them to language selection so each member can configure their own access.

  • Simple flow for new members
  • Moderation-side traceability
  • Explicit redirect to the language-selection channel (self-serve for members)
3

Scoped coordination

Creates interactive role/language messages for one group, several groups, or all TradLinker groups so members choose their language and only receive useful notifications.

  • Select one or multiple TradLinker groups
  • Safely update or delete coordination areas
  • Language roles reduce unnecessary notifications
4

Bulk and automatic role assignment

Select an existing role, assign it to eligible current members, then optionally choose an automatic rule for future members.

  • Bulk assignment for human members while respecting Discord’s role hierarchy
  • Choose one automation mode: on join or when the first role is received
  • Stop automation without removing roles already assigned

Commands

Admin-facing features (Premium)

All commands below are admin commands. TradCoord is intended for Premium servers.

👋 Welcome

  • /1-set_welcome — configures the welcome message (target channel + modal text)
  • /1-clear_welcome — disables and removes the server welcome configuration

Permissions: manage messages. Reserved for Premium servers.

📜 Rules + validation

  • /2-set_rules_message — sends a rules acceptance message with a button
  • Public settings: message channel, logs channel, language channel, role to assign
  • On click: assign role + confirmation message + link to the language-selection channel

🧩 Interactive coordination (creation)

  • /3-coordination — creates an interactive role-management message in a chosen channel
  • Lets you target one group, multiple groups, or all TradLinker groups
  • Creates/links language roles for the selected coordination area

✏️ Coordination maintenance

  • /3-edit_coordination — updates an existing coordination message (useful after changing groups/channels)
  • /3-delete_coordination — deletes a coordination area with confirmation
  • Safely cleans up unused permissions/roles when possible

Deletion: permissions Manage Messages + Manage Roles.

👥 Bulk role assignment

  • /4-role_assignment — selects an assignable existing role and distributes it to current members the bot can manage
  • Choose automatic assignment for new members or when a member receives their first role
  • /4-stop_role_assignment — disables automatic assignment for a configured role
  • Stopping automation does not remove roles already assigned

Premium server and Manage Roles permission required. The initial bulk assignment skips bots, and both the administrator’s and bot’s role hierarchies are respected.

✅ What this changes for your members

  • Clearer arrival flow (welcome + rules + language choice)
  • Less friction to reach the right content
  • Consistent assignment of a shared role without processing members one by one
  • Better readability for large multilingual servers

🎯 Best for which type of server?

  • Communities with significant onboarding needs (creators, gaming, support, schools)
  • Servers with many channels/languages and a need for structure
  • Moderation teams that want to save time on onboarding and shared roles
Important: TradCoord is a Premium add-on for TradLinker. Language coordination uses TradLinker groups and languages; bulk or automatic assignment can use any existing role that both the administrator and the bot are allowed to manage.
