چرا کاربران آن را دوست دارند

دستیار ساده برای کاربران، قدرتمند برای سرورها

TradAssist هم در پیام‌های خصوصی برای استفاده شخصی و هم مستقیماً در سرورها به‌عنوان افزونه ترجمه قابل استفاده است. ابزارهای سریع ترجمه Suite را وارد استفاده روزمره می‌کند.

1

ترجمه سریع بدون تنظیم پیچیده

یک پیام، متن تایپ‌شده یا محتوای اخیر کانال را با فرمان‌های slash و منوهای زمینه ترجمه کنید.

  • قابل استفاده در پیام خصوصی و سرورها (بسته به فرمان)
  • پاسخ‌های موقت برای تمیز ماندن کانال
  • انتخاب خودکار زبان مقصد بر اساس تنظیمات محلی
2

محتوای چندزبانه منتشر کنید

پست‌هایی با متن + پیوست و یک Translate دکمه می‌سازد و سپس ویرایش آسان آن‌ها را ممکن می‌کند.

  • ساخت سریع (پیوست‌ها + پنجره)
  • دکمه Translate برای خوانندگان
  • ویرایش پیام ربات با جریان درست مجوزها
3

واکنش پرچم = ترجمه فوری

اعضا با یک پرچم شناخته‌شده واکنش می‌دهند و TradAssist ترجمه موقت پیام را ارسال می‌کند.

  • بسیار ساده و قابل‌فهم برای اعضا
  • تأخیر حذف خودکار قابل تنظیم
  • فهرست پرچم‌های شناخته‌شده با فرمان قابل مشاهده است

فرمان‌ها

ویژگی‌های TradAssist (برای کاربران و سرورها)

فهرست کامل فرمان‌های slash و منوهای زمینه. سهمیه و استفاده نامحدود به طرح بستگی دارد (Free، سرور Premium، کاربر Platinium).

✍️ ترجمه و ارسال متن

  • /1-translate_and_send — انتخابگر زبان و سپس فرم متن برای ترجمه/ارسال را باز می‌کند
  • در سرورها، پیام خصوصی و کانال‌های خصوصی در دسترس است
  • برای نوشتن سریع پیام به زبان دیگر عالی است

🧾 پست‌های چندزبانه با دکمه Translate

  • /2-multilang_post_create — یک پست (متن + حداکثر ۵ پیوست) با یک Translate دکمه
  • /2-multilang_post_edit — پست موجود ربات را ویرایش می‌کند (متن + جایگزینی اختیاری پیوست)
  • در سرورها، پیام خصوصی و کانال‌های خصوصی قابل استفاده است

📚 ترجمه کانال (سرور)

  • /3-translate_channel — N پیام اخیر کانال را (حداکثر ۱۰۰) با صفحه‌بندی ترجمه می‌کند
  • منوی زمینه Translate channel — همان فرایند را از یک پیام باز می‌کند
  • فقط برای سرور (بدون پیام خصوصی)

💬 ترجمه یک پیام مشخص

  • /4-translate_message — یک پیام از کانال فعلی را با شناسه پیام ترجمه می‌کند
  • منوی زمینه Translate message — ساده‌ترین روش (کلیک راست / Apps)
  • در سرورها، پیام خصوصی و کانال‌های خصوصی در دسترس است
  • پاسخ موقت، مناسب برای ترجمه بدون شلوغ کردن کانال

🚩 ترجمه با واکنش پرچم

  • ویژگی مخصوص سرور: اعضا با پرچم شناخته‌شده واکنش می‌دهند تا ترجمه موقت دریافت کنند
  • /5-flagreact set_delay — تأخیر حذف خودکار را تنظیم می‌کند (۵ تا ۳۰۰ ثانیه)
  • /5-flagreact show — تأخیر فعلی را نشان می‌دهد
  • /5-flagreact list_flags — پرچم‌های شناخته‌شده را فهرست می‌کند

تنظیم set_delay: فرمان سرور که به Manage Server یا مجوز مدیر نیاز دارد.
