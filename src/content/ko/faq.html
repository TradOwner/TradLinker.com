FAQ — Discord 번역 봇

TradLinker, TradAssist, TradCoord에 관한 질문

자동 번역, 온보딩, 조정, 역할 부여, Premium / Platinium 요금제에 대한 명확한 답변입니다.

Discord 번역 봇이란 무엇인가요?

Discord 번역 봇은 멤버가 자신의 언어로 작성하면 다른 멤버에게 번역된 버전을 제공해 줍니다. TradLinker는 언어 채널을 연결하고, 메시지를 자동으로 번역하며, 커뮤니티 간 맥락을 유지하고, 해외 멤버를 별도의 대화로 나눌 필요를 줄여 다국어 Discord 서버에 최적화되어 있습니다.

TradLinker는 Discord 채널을 어떻게 자동 번역하나요?

TradLinker에서는 연결된 채널 그룹을 만들 수 있으며, 일반적으로 언어당 하나의 채널을 사용합니다. 누군가 한 채널에 메시지를 올리면 봇이 원문 언어를 감지하고 번역한 뒤 다른 연결 채널에 다시 게시하여 영어, 프랑스어, 스페인어 또는 기타 언어 커뮤니티가 같은 대화를 따라갈 수 있게 합니다.

TradLinker는 개별 Discord 메시지를 온디맨드로 번역할 수 있나요?

네. 이 제품군은 TradAssist 및 관련 번역 작업을 통해 온디맨드 번역을 지원합니다. 멤버는 특정 메시지의 번역을 요청하거나, 지원되는 반응을 사용하거나, 서버 전체가 자동 채널 중계에만 의존하지 않고 원하는 콘텐츠만 번역할 수 있습니다.

TradLinker는 다국어 게임 커뮤니티에 유용한가요?

네. 게임 커뮤니티에는 다양한 국가, 시간대, 언어 그룹의 플레이어가 함께하는 경우가 많습니다. TradLinker는 연결된 채널 사이의 대화를 번역하여 공지, 일반 채팅, 이벤트 조정, 지원 채널을 읽기 쉽게 유지하면서 언어별로 고립된 공간으로 나누지 않고 커뮤니티를 하나로 유지합니다.

TradLinker, TradAssist, TradCoord의 차이는 무엇인가요?

TradLinker는 연결된 다국어 채널을 위한 핵심 Discord 번역 봇입니다. TradAssist는 빠른 번역 작업, 개인 번역 지원, 서버 번역 확장 기능을 추가합니다. TradCoord는 온보딩, 규칙 동의, 언어 역할 조정, 일괄 또는 자동 역할 부여를 위한 Premium 계층입니다.

봇은 다국어 투표와 반응을 지원하나요?

TradLinker는 단순한 메시지 번역 이상의 기능을 위해 설계되었습니다. 제품군에는 다국어 투표, 동기화된 반응, 다국어 게시 도구가 포함되어 있어 관리자가 동일한 콘텐츠를 여러 번 수동 복제하지 않아도 멤버가 언어 채널 전반에서 투표하고 반응하며 공유 게시물을 이해할 수 있습니다.

Discord 번역 봇은 몇 개 언어를 지원하나요?

TradLinker는 100개 이상의 언어를 지원하여 국제 Discord 서버, 게임 클랜, 교육 그룹, 크리에이터 커뮤니티, 지원 공간에 적합합니다. 정확한 구성은 서버 설정, 연결된 채널, 할당량, 선택한 요금제에 따라 달라집니다.

TradLinker는 Discord 채널 전체를 번역할 수 있나요?

TradLinker는 연결된 채널과 자동 중계를 중심으로 구축되어 있으며, TradAssist는 선택한 콘텐츠를 위한 온디맨드 번역 도구를 추가합니다. 두 기능을 함께 사용하면 진행 중인 채널 활동과 특정 메시지를 번역하여 모든 내용을 외부 번역기에 복사하지 않고도 멤버가 토론을 따라갈 수 있습니다.

이 Discord 번역 봇에 무료 요금제가 있나요?

네. 무료 요금제로 핵심 TradLinker 경험을 시작하고 업그레이드 전에 다국어 채널 번역을 시험할 수 있습니다. Premium은 서버 한도를 늘리고 TradCoord 온보딩, 조정, 역할 부여를 추가하며, Platinium은 지원되는 환경에서 개인 TradAssist 사용을 위해 설계되었습니다.

Platinium 대신 Premium을 선택해야 하는 경우는 언제인가요?

전체 Discord 서버에 더 높은 한도, TradCoord 온보딩, 조정된 언어 역할, 일괄 또는 자동 역할 부여, 해당 서버 멤버의 확장된 TradAssist 사용이 필요하다면 Premium을 선택하세요. 한 명의 사용자가 지원되는 환경 전반에서 개인 TradAssist 접근 권한을 원한다면 Platinium을 선택하세요.

TradLinker가 언어 역할 온보딩을 도와줄 수 있나요?

네. TradCoord는 신규 멤버가 환영 메시지와 규칙을 읽고, 언어 역할을 선택하고, 적절한 접근 권한을 받도록 도와 TradLinker를 보완합니다. 관리자는 기존 역할을 현재 모든 멤버에게 부여한 뒤 신규 멤버 또는 멤버가 첫 역할을 받을 때 자동으로 부여하도록 설정할 수도 있습니다.

TradCoord는 멤버에게 역할을 자동으로 부여할 수 있나요?

네. Premium 서버에서 Manage Roles 권한을 가진 관리자는 /4-role_assignment 를 사용하여 현재 멤버에게 기존 역할을 부여한 다음 신규 멤버 또는 멤버가 첫 역할을 받을 때 자동 부여를 선택할 수 있습니다. /4-stop_role_assignment 는 이미 부여된 역할을 제거하지 않고 자동화를 중지합니다. 초기 일괄 부여는 봇을 건너뛰며 역할 계층을 준수합니다.

Discord 서버에서 TradLinker를 어떻게 시작하나요?

TradLinker를 추가하고 첫 연결 채널 그룹을 만든 뒤 두 언어 사이에서 메시지를 테스트하세요. 그런 다음 빠른 번역과 반응을 위해 TradAssist를 추가하세요. 서버가 성장하면 Premium으로 채널 한도를 늘리고 TradCoord를 추가하여 온보딩, 언어 조정, 일괄 또는 자동 역할 부여를 사용할 수 있습니다.
