제품군에서의 역할

TradCoord는 번역 이후를 담당합니다

TradCoord는 신규 멤버의 언어 선택을 안내하고, 적절한 접근 권한을 부여하며, 불필요한 알림을 줄입니다. 또한 기존 역할을 현재 모든 멤버에게 배포한 뒤 신규 멤버나 첫 역할을 받는 멤버에게 자동으로 부여할 수 있습니다.

1

맞춤 환영

전체 서버에 불필요한 알림을 보내지 않고 멤버를 올바른 채널(규칙 / 언어 선택)로 안내하는 맞춤 환영 메시지를 설정하세요.

  • 자유 텍스트(모달 사용)
  • 간단한 변수 {user} and {channel}
  • 사용자를 규칙 또는 언어 선택 채널로 바로 보내는 버튼
2

규칙 동의

동의 버튼이 있는 규칙 메시지를 게시하고 사용자에게 역할을 부여한 다음 언어 선택으로 리디렉션하여 각 멤버가 자신의 접근 권한을 구성할 수 있게 합니다.

  • 신규 멤버를 위한 간단한 흐름
  • 관리자 측 추적성
  • 언어 선택 채널로 명시적 리디렉션(멤버 셀프서비스)
3

범위 기반 조정

하나의 그룹, 여러 그룹 또는 모든 TradLinker 그룹에 대해 대화형 역할/언어 메시지를 만들어 멤버가 언어를 선택하고 유용한 알림만 받도록 합니다.

  • 하나 이상의 TradLinker 그룹 선택
  • 조정 영역을 안전하게 업데이트 또는 삭제
  • 언어 역할로 불필요한 알림 감소
4

일괄 및 자동 역할 부여

기존 역할을 선택하고 적격 현재 멤버에게 부여한 다음, 선택적으로 향후 멤버를 위한 자동 규칙을 선택합니다.

  • Discord 역할 계층을 준수하면서 실제 멤버에게 일괄 부여
  • 자동화 모드 하나 선택: 가입 시 또는 첫 역할을 받을 때
  • 이미 부여된 역할을 제거하지 않고 자동화 중지

명령

관리자용 기능(Premium)

아래 모든 명령은 관리자 명령입니다. TradCoord는 Premium 서버용입니다.

👋 환영

  • /1-set_welcome — 환영 메시지 설정(대상 채널 + 모달 텍스트)
  • /1-clear_welcome — 서버 환영 설정 비활성화 및 제거

권한: 메시지 관리. Premium 서버 전용.

📜 규칙 + 확인

  • /2-set_rules_message — 버튼이 있는 규칙 동의 메시지 전송
  • 공개 설정: 메시지 채널, 로그 채널, 언어 채널, 부여할 역할
  • 클릭 시: 역할 부여 + 확인 메시지 + 언어 선택 채널 링크

🧩 대화형 조정(생성)

  • /3-coordination — 선택한 채널에 대화형 역할 관리 메시지 생성
  • 하나의 그룹, 여러 그룹 또는 모든 TradLinker 그룹을 대상으로 설정 가능
  • 선택한 조정 영역의 언어 역할 생성/연결

✏️ 조정 유지 관리

  • /3-edit_coordination — 기존 조정 메시지 업데이트(그룹/채널 변경 후 유용)
  • /3-delete_coordination — 확인 후 조정 영역 삭제
  • 가능한 경우 사용하지 않는 권한/역할을 안전하게 정리

삭제: 권한 메시지 관리 + Manage Roles.

👥 일괄 역할 부여

  • /4-role_assignment — 부여 가능한 기존 역할을 선택하고 봇이 관리할 수 있는 현재 멤버에게 배포
  • 신규 멤버 또는 멤버가 첫 역할을 받을 때 자동 부여 선택
  • /4-stop_role_assignment — 설정된 역할의 자동 부여 비활성화
  • 자동화를 중지해도 이미 부여된 역할은 제거되지 않습니다

Premium 서버 및 Manage Roles 권한이 필요합니다. 초기 일괄 부여는 봇을 건너뛰며 관리자와 봇의 역할 계층을 모두 준수합니다.

✅ 멤버에게 달라지는 점

  • 더 명확한 가입 흐름(환영 + 규칙 + 언어 선택)
  • 올바른 콘텐츠에 도달하기 위한 마찰 감소
  • 멤버를 한 명씩 처리하지 않고 공통 역할을 일관되게 부여
  • 대규모 다국어 서버의 가독성 향상

🎯 어떤 유형의 서버에 가장 적합한가요?

  • 온보딩 요구가 큰 커뮤니티(크리에이터, 게임, 지원, 학교)
  • 채널/언어가 많고 구조가 필요한 서버
  • 온보딩과 공통 역할 관리 시간을 줄이고 싶은 모더레이션 팀
중요: TradCoord는 Premium 추가 기능 입니다. TradLinker의 언어 조정은 TradLinker 그룹과 언어를 사용하며, 일괄 또는 자동 부여에는 관리자와 봇 모두 관리 권한이 있는 기존 역할을 사용할 수 있습니다.
