왜 이 제품군인가요?

명확한 구조: 메인 봇 1개 + 보완 확장 기능 2개

세 봇은 다음과 같이 함께 작동합니다: TradLinker 는 메인 봇이며, TradCoord 는 Premium 온보딩, 조정 및 역할 관리 추가 기능이고, TradAssist 는 개인 도우미와 서버 번역 확장 기능 역할을 모두 수행합니다.

1

TradLinker로 시작하기

연결된 채널 그룹(FR / EN / ES…)을 만들고 봇이 메시지를 중계/번역하게 하여 대화를 분산시키지 않고 하나로 유지하세요.

  • 채널 간 자동 번역
  • 동기화된 반응
  • 다국어 투표
2

일상적인 사용을 위해 TradAssist 추가

온디맨드 번역, 채널 번역 및 Translate 버튼이 있는 다국어 게시물과 국기 반응 번역. Premium에서는 주요 지원 기능을 해당 서버의 모든 멤버가 무제한으로 사용할 수 있습니다.

  • DM 개인 도우미
  • 서버 번역 도구
  • Premium 서버에서 무제한(지원 기능)
3

Premium으로 TradCoord 잠금 해제

깔끔하고 안전한 온보딩: 환영 메시지, 규칙 동의, 언어 선택, 다중 그룹 조정, 현재 또는 향후 멤버를 위한 역할 부여.

  • 환영 및 규칙
  • 언어 역할 및 조정
  • 일괄 또는 자동 부여

도우미 및 확장 기능

TradAssist

개인 번역 도우미… 그리고 TradLinker의 서버 확장 기능. DM과 서버에서 사용할 수 있는 고급 번역 도구.

메시지 번역채널 번역다국어 게시물국기 반응
주요 기능 / 명령
  • /1-translate_and_send • /4-translate_message
  • /3-translate_channel + 컨텍스트 메뉴 Translate channel
  • /2-multilang_post_create / edit 다음이 포함된 Translate 버튼
  • /5-flagreact 명령 그룹(국기 + 지연 시간)
  • /6-buy_platinium — 사용자 Platinium 요금제

Premium 확장 기능

TradCoord

Premium 서버를 위한 스마트 온보딩. 멤버를 환영하고, 규칙과 언어 역할을 관리하고, 접근 권한을 조정하며, 역할 부여를 자동화합니다.

환영규칙언어 역할조정자동 역할
주요 기능 / 명령
  • /1-set_welcome • /1-clear_welcome
  • /2-set_rules_message (동의 버튼 + 로그)
  • /3-coordination, /3-edit_coordination, /3-delete_coordination
  • /4-role_assignment • /4-stop_role_assignment (일괄 및 자동 부여)
  • 전용 Premium

워크플로

3개 봇이 서로 보완하는 방식

1

TradLinker가 대화를 구조화합니다

언어별 연결 채널 그룹, 자동 중계와 번역을 통해 대화를 활발하고 통합된 상태로 유지합니다.

2

TradAssist가 고급 도구를 추가합니다

온디맨드 번역, 채널 번역, 다국어 게시물, 국기 반응 — DM 및/또는 서버에서.

3

TradCoord가 Premium 온보딩과 역할을 구조화합니다

규칙, 언어, 역할 및 접근 권한: 명확한 흐름, 대화형 언어 선택, 현재 또는 향후 멤버에 대한 자동 역할 부여.
