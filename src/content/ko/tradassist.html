사용자가 좋아하는 이유

사용자에게는 간단하고 서버에는 강력한 도우미

TradAssist는 개인 용도로 DM에서 사용할 수 있을 뿐 아니라 서버에서 번역 확장 기능으로 직접 사용할 수도 있습니다. 제품군의 빠른 번역 작업을 일상적인 사용에 제공합니다.

1

복잡한 설정 없이 빠른 번역

슬래시 명령과 컨텍스트 메뉴를 통해 메시지, 입력한 텍스트 또는 최근 채널을 번역하세요.

  • DM 및 서버에서 사용(명령에 따라 다름)
  • 채널을 깔끔하게 유지하는 임시 응답
  • 로케일에 따른 자동 대상 언어 선택
2

다국어 콘텐츠 게시

텍스트 + 첨부 파일과 Translate 버튼이 포함된 게시물을 만들고 이후 쉽게 수정할 수 있습니다.

  • 빠른 생성(첨부 파일 + 모달)
  • 독자를 위한 번역 버튼
  • 올바른 권한 흐름을 통한 봇 메시지 편집
3

국기 반응 = 즉시 번역

멤버가 인식되는 국기로 반응하면 TradAssist가 해당 메시지의 임시 번역을 전송합니다.

  • 멤버가 매우 직관적으로 사용 가능
  • 설정 가능한 자동 삭제 지연 시간
  • 명령으로 인식되는 국기 목록 확인 가능

명령

TradAssist 기능(사용자 및 서버용)

슬래시 명령과 컨텍스트 메뉴의 전체 목록입니다. 할당량과 무제한 사용 여부는 요금제(Free, 서버 Premium, 사용자 Platinium)에 따라 달라집니다.

✍️ 텍스트 번역 및 전송

  • /1-translate_and_send — 언어 선택기를 연 다음 번역/전송할 텍스트 양식을 엽니다
  • 서버, DM, 비공개 채널에서 사용 가능
  • 다른 언어로 메시지를 빠르게 작성할 때 이상적

🧾 번역 버튼이 있는 다국어 게시물

  • /2-multilang_post_create — 다음을 포함한 게시물 생성(텍스트 + 최대 5개 첨부 파일) Translate 버튼
  • /2-multilang_post_edit — 기존 봇 게시물 편집(텍스트 + 선택적 첨부 파일 교체)
  • 서버, DM, 비공개 채널에서 사용 가능

📚 채널 번역(서버)

  • /3-translate_channel — 다음을 번역합니다 최근 N개 메시지 채널에서(최대 100개), 페이지 나누기 포함
  • 컨텍스트 메뉴 Translate channel — 메시지에서 동일한 흐름을 엽니다
  • 서버 전용 명령(DM 불가)

💬 특정 메시지 번역

  • /4-translate_message — 현재 채널의 메시지를 번역합니다(메시지 ID 사용)
  • 컨텍스트 메뉴 Translate message — 가장 쉬운 방법(오른쪽 클릭 / 앱)
  • 서버, DM, 비공개 채널에서 사용 가능
  • 채널을 어지럽히지 않고 번역하는 데 유용한 임시 응답

🚩 국기 반응을 통한 번역

  • 서버 전용 기능: 멤버가 인식되는 국기로 반응하면 임시 번역을 받습니다
  • /5-flagreact set_delay — 자동 삭제 지연 시간 설정(5~300초)
  • /5-flagreact show — 현재 지연 시간 표시
  • /5-flagreact list_flags — 인식되는 국기 목록 표시

설정 set_delay: 다음 권한이 필요한 서버 명령 Manage Server 또는 관리자 권한.

💎 사용자 구독

  • /6-buy_platinium — Platinium 구독 절차 열기/안내
  • 서버, DM, 비공개 채널에서 사용할 수 있는 명령
  • 지원되는 기능을 개인적으로 무제한 사용할 때 유용
참고: TradAssist는 제품군에서 가장 직접적으로 사용할 수 있는 봇입니다. DM에서 한 사용자를 지원할 수도 있고 or 특히 TradLinker와 함께 서버용 완전한 번역 확장 기능이 될 수도 있습니다.
