TradLinker가 하는 일

여러 언어로 이어지는 하나의 대화 흐름

TradLinker는 대화가 분산되는 것을 방지하도록 설계되었습니다. 커뮤니티를 나누는 대신 채널 그룹(FR, EN, ES 등)을 만들면 봇이 각 메시지를 번역과 함께 그룹의 다른 채널로 중계합니다.

1

연결된 채널 그룹

그룹을 만듭니다(예: 일반) 그런 다음 언어당 하나의 채널을 추가합니다. TradLinker는 각 메시지를 어디에 다시 게시해야 하는지 알게 됩니다.

  • 그룹 기반 구성(예: 일반, 지원, 모집)
  • 그룹에서 하나의 채널 = 하나의 언어
  • 설정은 언제든 확인하고 수정할 수 있습니다
2

자동 중계 + 번역

멤버가 연결된 채널에 메시지를 게시하면 해당 메시지가 같은 그룹의 다른 채널에 각 언어에 맞는 번역과 함께 다시 게시됩니다.

  • 원활한 멤버 경험
  • 언어를 아우르는 하나의 통합 대화
  • 중계된 메시지의 반응, Discord 답글 및 원위치 편집 자동 동기화
  • 반응 뷰어를 통해 반응 확인 가능
3

내장 다국어 투표

연결된 채널에서 투표를 시작하면 봇이 번역된 선택지와 함께 그룹의 모든 채널로 전송합니다.

  • 질문 + 선택지가 언어별로 번역됨
  • 연결된 채널 전체에 동기화된 전송
  • 작성자(또는 관리자)가 투표를 쉽게 삭제

명령

관리자 / 모더레이터가 매일 사용하는 모든 기능

아래: 사용자/관리자에게 표시되는 명령과 작업입니다.

🧭 시작하기

  • /help — TradLinker 빠른 설정 가이드(그룹, 채널, premium, 지원)
  • 알아두세요: 봇이 설정 과정을 단계별로 안내하여 빠르게 시작할 수 있습니다

🛠️ 그룹 설정(서버 관리자)

  • /2-create_group — 연결된 채널 그룹 생성
  • /3-add_channel — 그룹에 채널을 추가한 후 언어 선택 안내
  • /4-remove_channel — 그룹에서 채널 제거
  • /5-delete_group — 전체 그룹 삭제
  • /6-show_groups — 현재 설정 표시(그룹 + 채널 + 언어)

주로 서버에서 사용 • 설정 명령에는 Manage Channels 권한이 필요합니다.

📊 다국어 투표

  • /1-create_poll — 연결된 채널에서 투표를 만들고 그룹의 연결 채널에 전송
  • /1-delete_poll — 자신이 만든 투표 삭제(관리자는 모든 투표 삭제 가능)
  • 내장 기간 프리셋(15분~3일)
  • 텍스트 선택지(전체 기능 사용 시 답변별 선택적 이미지 포함)

💬 반응 뷰어

  • 컨텍스트 메뉴 Show reactions — 메시지 반응을 집계된 형태로 표시
  • 중계 / 번역 메시지 시스템에서 매우 유용

💎 지원 및 서버 구독

  • /7-donate — 프로젝트 후원
  • /8-buy_premium — 현재 서버의 Premium 구독

Premium은 그룹 및 채널 한도를 높이고 TradCoord(온보딩, 규칙, 조정, 역할 부여)에 대한 접근을 열며 해당 서버에서 TradAssist를 무제한으로 사용할 수 있게 합니다.

🎯 어떤 용도에 가장 적합한가요?

  • 국제 커뮤니티(게임, 크리에이터, 지원, 오픈 소스)
  • 다음을 유지하고 싶은 서버 하나의 단일 커뮤니티 언어별로 나누지 않고
  • 관리하기 쉽고 안정적인 설정이 필요한 팀
Free vs Premium 요금제: TradLinker에는 이미 핵심 다국어 채팅 시스템이 포함되어 있습니다. Premium은 설정 한도(그룹/채널)를 높이고 TradCoord 온보딩, 조정 및 역할 부여를 추가하며, 서버에서 지원되는 TradAssist 기능을 무제한으로 사용할 수 있게 합니다.
