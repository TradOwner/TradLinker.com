🚀 Een server upgraden naar Premium

  1. Voer op de server die je naar Premium wilt upgradende opdracht uit /8-buy_premium.
  2. De bot genereert en verzendt een Stripe-betaallink (veilige betalingsprovider) om je te abonneren op het Premium-abonnement van de server.
  3. Zodra de betaling is ontvangen en bevestigd, wordt de server automatisch als Premium geregistreerd.

De opdracht moet op de doelserver worden uitgevoerd, omdat het Premium-abonnement aan die server is gekoppeld.

💎 Platinium-gebruiker worden

  1. Voer de opdracht uit /6-buy_platinium (server, DM of privékanaal).
  2. De bot maakt/toont de beveiligde abonnementslink om de Platinium-aanmelding te voltooien.
  3. Zodra de betaling is bevestigd, wordt het gebruikersaccount automatisch als Platinium geregistreerd.

Dit abonnement is gekoppeld aan de gebruiker (niet aan een volledige server).
