Чому він подобається користувачам

Простий помічник для користувачів, потужний для серверів

TradAssist можна використовувати в особистих повідомленнях для власних потреб, а також безпосередньо на серверах як розширення перекладу. Він переносить швидкі дії перекладу набору в повсякденне використання.

1

Швидкі переклади без складного налаштування

Перекладайте повідомлення, введений текст або нещодавні повідомлення каналу через slash-команди та контекстні меню.

  • Використання в DM і на серверах (залежно від команди)
  • Тимчасові відповіді, щоб канал залишався чистим
  • Автоматичний вибір цільової мови на основі локалі
2

Публікуйте багатомовний контент

Створює дописи з текстом + вкладеннями та Translate кнопкою, а потім дозволяє легко редагувати ці дописи.

  • Швидке створення (вкладення + модальне вікно)
  • Кнопка «Перекласти» для читачів
  • Редагування повідомлень бота з правильним процесом дозволів
3

Реакції прапорцями = миттєвий переклад

Учасники реагують розпізнаним прапорцем, і TradAssist надсилає тимчасовий переклад повідомлення.

  • Дуже інтуїтивно для учасників
  • Налаштовувана затримка автоматичного видалення
  • Список розпізнаваних прапорців доступний за командою

Команди

Функції TradAssist (для користувачів і серверів)

Повний список slash-команд і контекстних меню. Квоти та необмежене використання залежать від тарифу (Free, сервер Premium, користувач Platinium).

✍️ Перекласти й надіслати текст

  • /1-translate_and_send — відкриває вибір мови, а потім текстову форму для перекладу/надсилання
  • Доступно на серверах, у DM і приватних каналах
  • Ідеально для швидкого написання повідомлення іншою мовою

🧾 Багатомовні дописи з кнопкою «Перекласти»

  • /2-multilang_post_create — створює допис (текст + до 5 вкладень) із Translate кнопкою
  • /2-multilang_post_edit — редагує наявний допис бота (текст + необов’язкова заміна вкладень)
  • Можна використовувати на серверах, у DM і приватних каналах

📚 Переклад каналу (сервер)

  • /3-translate_channel — перекладає N останніх повідомлень із каналу (макс. 100) зі сторінками
  • Контекстне меню Translate channel — відкриває той самий процес із повідомлення
  • Команда лише для сервера (без DM)

💬 Перекласти конкретне повідомлення

  • /4-translate_message — перекладає повідомлення з поточного каналу (за ID повідомлення)
  • Контекстне меню Translate message — найпростіший спосіб (правий клік / Застосунки)
  • Доступно на серверах, у DM і приватних каналах
  • Тимчасова відповідь, корисна для перекладу без захаращення каналу

🚩 Переклад через реакції прапорцями

  • Функція лише для сервера: учасники реагують розпізнаним прапорцем і отримують тимчасовий переклад
  • /5-flagreact set_delay — задає затримку автоматичного видалення (від 5 до 300 с)
  • /5-flagreact show — показує поточну затримку
  • /5-flagreact list_flags — показує список розпізнаваних прапорців

Налаштування set_delay: серверна команда, що потребує Manage Server або прав адміністратора.

💎 Підписка користувача

  • /6-buy_platinium — відкриває/проводить через процес підписки Platinium
  • Команда доступна на серверах, у DM і приватних каналах
  • Корисно для необмеженого особистого використання підтримуваних функцій
