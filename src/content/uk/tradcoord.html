Роль у наборі

TradCoord бере роботу на себе після перекладу

TradCoord проводить нових учасників через вибір мови, призначає правильний доступ і обмежує непотрібні сповіщення. Він також може роздати наявну роль усім поточним учасникам, а потім автоматизувати її для нових учасників або коли вони отримують першу роль.

1

Власне привітання

Налаштуйте власне привітання, щоб направляти учасників у правильний канал (правила / вибір мови) без непотрібних сповіщень для всього сервера.

  • Довільний текст (через модальне вікно)
  • Прості змінні {user} and {channel}
  • Кнопка, що одразу направляє користувачів до каналу правил або вибору мови
2

Прийняття правил

Публікує повідомлення з правилами та кнопкою прийняття, призначає користувачеві роль, а потім перенаправляє до вибору мови, щоб кожен учасник міг налаштувати власний доступ.

  • Простий процес для нових учасників
  • Відстежуваність для модерації
  • Явне перенаправлення до каналу вибору мови (самообслуговування для учасників)
3

Координація за областю

Створює інтерактивні повідомлення ролей/мов для однієї, кількох або всіх груп TradLinker, щоб учасники обирали свою мову й отримували лише корисні сповіщення.

  • Виберіть одну або кілька груп TradLinker
  • Безпечно оновлюйте або видаляйте області координації
  • Мовні ролі зменшують непотрібні сповіщення
4

Масове й автоматичне призначення ролей

Виберіть наявну роль, призначте її відповідним поточним учасникам, а потім за бажанням оберіть автоматичне правило для майбутніх учасників.

  • Масове призначення реальним учасникам із дотриманням ієрархії ролей Discord
  • Виберіть один режим автоматизації: при вході або при отриманні першої ролі
  • Зупиніть автоматизацію без видалення вже призначених ролей

Команди

Функції для адміністраторів (Premium)

Усі команди нижче є адміністративними. TradCoord призначений для Premium-серверів.

👋 Привітання

  • /1-set_welcome — налаштовує привітання (цільовий канал + текст модального вікна)
  • /1-clear_welcome — вимикає та видаляє серверну конфігурацію привітання

Дозволи: керування повідомленнями. Лише для Premium-серверів.

📜 Правила + підтвердження

  • /2-set_rules_message — надсилає повідомлення про прийняття правил із кнопкою
  • Публічні налаштування: канал повідомлення, канал журналів, мовний канал, роль для призначення
  • Після натискання: призначення ролі + підтвердження + посилання на канал вибору мови

🧩 Інтерактивна координація (створення)

  • /3-coordination — створює інтерактивне повідомлення керування ролями у вибраному каналі
  • Дозволяє вибрати одну, кілька або всі групи TradLinker
  • Створює/пов’язує мовні ролі для вибраної області координації

✏️ Обслуговування координації

  • /3-edit_coordination — оновлює наявне повідомлення координації (корисно після зміни груп/каналів)
  • /3-delete_coordination — видаляє область координації з підтвердженням
  • За можливості безпечно очищує невикористані дозволи/ролі

Видалення: дозволи Керування повідомленнями + Manage Roles.

👥 Масове призначення ролей

  • /4-role_assignment — вибирає наявну роль, яку можна призначити, і роздає її поточним учасникам, якими бот може керувати
  • Виберіть автоматичне призначення новим учасникам або коли учасник отримує свою першу роль
  • /4-stop_role_assignment — вимикає автоматичне призначення для налаштованої ролі
  • Зупинка автоматизації не видаляє вже призначені ролі

Premium-сервер і Manage Roles потрібний дозвіл. Початкове масове призначення пропускає ботів і дотримується ієрархій ролей адміністратора та бота.

✅ Що це змінює для ваших учасників

  • Зрозуміліший процес входу (привітання + правила + вибір мови)
  • Менше перешкод для переходу до потрібного контенту
  • Послідовне призначення спільної ролі без обробки учасників по одному
  • Краща читабельність для великих багатомовних серверів

🎯 Для якого типу сервера це найкраще?

  • Спільноти зі значними потребами в онбордингу (автори, ігри, підтримка, школи)
  • Сервери з великою кількістю каналів/мов і потребою в структурі
  • Команди модерації, які хочуть економити час на онбордингу та спільних ролях
Важливо: TradCoord — це Premium-доповнення для TradLinker. Мовна координація використовує групи й мови TradLinker; масове або автоматичне призначення може використовувати будь-яку наявну роль, якою дозволено керувати і адміністратору, і боту.
