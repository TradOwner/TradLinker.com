ユーザーに好まれる理由

ユーザーには簡単、サーバーには強力なアシスタント

TradAssistは個人利用としてDMで使えるだけでなく、翻訳拡張としてサーバー上でも直接利用できます。Suiteの素早い翻訳操作を日常利用に取り込みます。

1

複雑な設定なしで素早く翻訳

Slashコマンドやコンテキストメニューから、メッセージ、入力したテキスト、最近のチャンネルを翻訳できます。

  • DMとサーバーで利用可能（コマンドによる）
  • チャンネルを散らかさない一時的な応答
  • ロケールに基づく対象言語の自動選択
2

多言語コンテンツを公開

テキスト + 添付ファイルの投稿を Translate ボタン付きで作成し、その投稿を簡単に編集できます。

  • 素早く作成（添付 + モーダル）
  • 読者向けTranslateボタン
  • 適切な権限フローでボットメッセージを編集
3

国旗リアクション = 即時翻訳

メンバーが認識済みの国旗でリアクションすると、TradAssistがメッセージの一時翻訳を送信します。

  • メンバーにとって非常に直感的
  • 自動削除までの時間を設定可能
  • 認識される国旗一覧をコマンドで確認可能

コマンド

TradAssistの機能（ユーザー・サーバー向け）

Slashコマンドとコンテキストメニューの完全一覧。利用枠と無制限利用はプラン（Free、サーバーPremium、ユーザーPlatinium）によって異なります。

✍️ テキストを翻訳して送信

  • /1-translate_and_send — 言語セレクターを開き、その後、翻訳/送信用のテキストフォームを表示
  • サーバー、DM、プライベートチャンネルで利用可能
  • 別の言語で素早くメッセージを書くのに最適

🧾 Translateボタン付き多言語投稿

  • /2-multilang_post_create — 投稿（テキスト + 最大5個の添付）を Translate ボタンを搭載
  • /2-multilang_post_edit — 既存のボット投稿を編集（テキスト + 必要に応じて添付を置換）
  • サーバー、DM、プライベートチャンネルで利用可能

📚 チャンネル翻訳（サーバー）

  • /3-translate_channel — チャンネルの 最新N件のメッセージ （最大100件）をページ分割して翻訳
  • コンテキストメニュー Translate channel — メッセージから同じフローを開く
  • サーバー専用コマンド（DM不可）

💬 特定のメッセージを翻訳

  • /4-translate_message — 現在のチャンネルからメッセージIDを使って翻訳
  • コンテキストメニュー Translate message — 最も簡単な方法（右クリック / Apps）
  • サーバー、DM、プライベートチャンネルで利用可能
  • チャンネルを散らかさず翻訳できる一時的な応答

🚩 国旗リアクションによる翻訳

  • サーバー専用機能：認識済みの国旗でリアクションすると一時翻訳を取得
  • /5-flagreact set_delay — 自動削除までの時間を設定（5〜300秒）
  • /5-flagreact show — 現在の遅延時間を表示
  • /5-flagreact list_flags — 認識される国旗を一覧表示

設定 set_delay：サーバーコマンドで、 Manage Server または管理者権限が必要です。

💎 ユーザーサブスクリプション

  • /6-buy_platinium — Platinium購読フローを開く/案内する
  • サーバー、DM、プライベートチャンネルで利用可能なコマンド
  • 対応機能を個人で無制限利用するのに便利
