Por qué gusta a los usuarios

Un asistente sencillo para usuarios, potente para servidores

TradAssist puede usarse en mensajes directos para uso personal, pero también directamente en servidores como extensión de traducción. Lleva las acciones rápidas de traducción de la suite al uso cotidiano.

1

Traducciones rápidas, sin configuración compleja

Traduce un mensaje, texto escrito o un canal reciente mediante comandos slash y menús contextuales.

  • Uso en DM y servidores (según el comando)
  • Respuestas efímeras para mantener limpio el canal
  • Selección automática del idioma objetivo según la configuración regional
2

Publica contenido multilingüe

Crea publicaciones con texto + archivos adjuntos y un Translate botón, y después permite editar fácilmente esas publicaciones.

  • Creación rápida (adjuntos + modal)
  • Botón Translate para los lectores
  • Edición de mensajes del bot con el flujo de permisos correcto
3

Reacciones con banderas = traducción instantánea

Los miembros reaccionan con una bandera reconocida y TradAssist envía una traducción temporal del mensaje.

  • Muy intuitivo para los miembros
  • Retraso de eliminación automática configurable
  • Lista de banderas reconocidas disponible mediante comando

Comandos

Funciones de TradAssist (para usuarios y servidores)

Lista completa de comandos slash y menús contextuales. Las cuotas y el uso ilimitado dependen del plan (Free, servidor Premium, usuario Platinium).

✍️ Traducir y enviar texto

  • /1-translate_and_send — abre un selector de idioma y después un formulario de texto para traducir/enviar
  • Disponible en servidores, DM y canales privados
  • Ideal para escribir rápidamente un mensaje en otro idioma

🧾 Publicaciones multilingües con botón Translate

  • /2-multilang_post_create — crea una publicación (texto + hasta 5 archivos adjuntos) con un Translate botón
  • /2-multilang_post_edit — edita una publicación existente del bot (texto + sustitución opcional de adjuntos)
  • Puede usarse en servidores, DM y canales privados

📚 Traducción de canal (servidor)

  • /3-translate_channel — traduce los N mensajes más recientes del canal (máx. 100) con paginación
  • Menú contextual Translate channel — abre el mismo flujo desde un mensaje
  • Comando solo para servidores (sin DM)

💬 Traducir un mensaje concreto

  • /4-translate_message — traduce un mensaje del canal actual (mediante ID del mensaje)
  • Menú contextual Translate message — el método más sencillo (clic derecho / Apps)
  • Disponible en servidores, DM y canales privados
  • Respuesta efímera, útil para traducir sin llenar el canal

🚩 Traducción mediante reacciones con banderas

  • Función solo para servidores: los miembros reaccionan con una bandera reconocida para obtener una traducción temporal
  • /5-flagreact set_delay — establece el retraso de eliminación automática (de 5 a 300 s)
  • /5-flagreact show — muestra el retraso actual
  • /5-flagreact list_flags — enumera las banderas reconocidas

Configuración set_delay: comando de servidor que requiere Manage Server o permisos de administrador.

💎 Suscripción de usuario

  • /6-buy_platinium — abre/guía el flujo de suscripción Platinium
  • Comando disponible en servidores, DM y canales privados
  • Útil para uso personal ilimitado de las funciones compatibles
Ten en cuenta: TradAssist es el bot más directo de la suite. Puede ayudar a un usuario en DM or convertirse en una extensión de traducción completa para un servidor — especialmente junto a TradLinker.
