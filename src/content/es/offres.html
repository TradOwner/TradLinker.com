🚀 Cómo mejorar un servidor a Premium

  1. Desde el servidor que quieres mejorar a Premium, ejecuta el comando /8-buy_premium.
  2. El bot genera y envía un enlace de pago de Stripe (proveedor de pago seguro) para suscribirse al plan Premium del servidor.
  3. Una vez recibido y confirmado el pago, el servidor queda registrado automáticamente como Premium.

El comando debe ejecutarse en el servidor de destino, porque la suscripción Premium está vinculada a ese servidor.

💎 Cómo convertirse en usuario Platinium

  1. Ejecuta el comando /6-buy_platinium (servidor, DM o canal privado).
  2. El bot crea/muestra el enlace seguro de suscripción para completar el alta en Platinium.
  3. Una vez confirmado el pago, la cuenta del usuario queda registrada automáticamente como Platinium.

Esta suscripción está vinculada al usuario (no a un servidor completo).
